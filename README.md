# PSC---Optimisation-de-route-maritime
PSC with CMA CGM (Fleet Center): computing an optimal ship route and speed profile under weather uncertainty (waves, wind, currents). Multi-objective (CO₂, cost, safety) with operational constraints: arrival time, restricted zones, bathymetry, ship limits. Must run in under 30 min. Team of 6 X students, weekly meetings with CMA CGM.
